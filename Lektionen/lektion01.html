🧾 Einkaufslisten-Projekt in Python

Ziel: Du entwickelst ein Programm, mit dem man eine einfache Einkaufsliste verwalten kann.

Am Ende kann man Artikel hinzufügen, anzeigen, löschen und das Programm beenden.

🧩 Baustein 1 – Eine Liste erstellen

Auftrag: Lege eine leere Liste an, in der später alle Artikel gespeichert werden.

einkaufsliste = []
Teste: Schreibe print(einkaufsliste) und überprüfe, ob die Liste leer ist.
🧩 Baustein 2 – Artikel hinzufügen

Auftrag: Schreibe Code, der den Benutzer nach einem Artikel fragt und ihn in die Liste einfügt.

artikel = input("Welchen Artikel möchtest du hinzufügen? ")
einkaufsliste.append(artikel)
print(einkaufsliste)
Teste: Starte das Programm mehrmals. Funktioniert das Hinzufügen?
🧩 Baustein 3 – Liste anzeigen

Auftrag: Zeige alle gespeicherten Artikel mit einer Nummer davor an.

for i in range(len(einkaufsliste)):
    print(i + 1, "-", einkaufsliste[i])
Teste: Füge zuerst ein paar Artikel hinzu, dann zeige die Liste an.
🧩 Baustein 4 – Artikel löschen

Auftrag: Frage den Benutzer, welche Nummer gelöscht werden soll, und entferne den passenden Artikel.

nummer = int(input("Welche Nummer soll gelöscht werden? "))
einkaufsliste.pop(nummer - 1)
Teste: Lösche einen Artikel und zeige danach die Liste an.
🧩 Baustein 5 – Alles zusammenführen

Auftrag: Baue aus allen Bausteinen ein Menü, das sich wiederholt, bis der Benutzer „4“ wählt.

einkaufsliste = []

while True:
    print("\n--- Einkaufslisten-Manager ---")
    print("1. Artikel hinzufügen")
    print("2. Artikel anzeigen")
    print("3. Artikel löschen")
    print("4. Beenden")

    wahl = input("Wähle eine Zahl (1-4): ")

    if wahl == "1":
        artikel = input("Welchen Artikel möchtest du hinzufügen? ")
        einkaufsliste.append(artikel)

    elif wahl == "2":
        for i in range(len(einkaufsliste)):
            print(i + 1, "-", einkaufsliste[i])

    elif wahl == "3":
        nummer = int(input("Welche Nummer soll gelöscht werden? "))
        einkaufsliste.pop(nummer - 1)

    elif wahl == "4":
        break
Teste: Funktioniert das Menü vollständig? Kannst du Artikel hinzufügen, anzeigen und löschen?
💡 Erweiterungsideen (für Schnellere)
  • Frage beim Start nach dem Namen des Benutzers.
  • Gib am Ende alle verbleibenden Artikel aus.
  • Zähle, wie viele Artikel insgesamt hinzugefügt wurden.
